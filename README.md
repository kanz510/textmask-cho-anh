# Textmask cho ảnh

Công cụ tạo textmask (watermark chữ) cho ảnh, chạy hoàn toàn trên trình duyệt — không cần cài đặt hay máy chủ.

- Tải ảnh lên (chọn file, kéo thả hoặc dán), gõ chữ rồi phủ chữ lên ảnh với 10 kiểu: lưới, xen kẽ, chéo xiên, dải ngang, cột dọc, rải ngẫu nhiên, giữa ảnh, chữ lớn phủ, bốn góc + giữa, viền khung.
- 11 phông chữ, 7 hiệu ứng chữ (viền, bóng đổ, phát sáng, chuyển màu, nổi 3D, nền sau chữ...), 6 mẫu chữ sẵn, watermark bằng logo, xử lý hàng loạt.
- Phím tắt bàn phím: Ctrl/Cmd+O mở ảnh, Ctrl+S tải PNG, Ctrl+Shift+S tải JPG, phím 1–0 đổi kiểu phủ.
- Tải xuống PNG/JPG đúng kích thước gốc của ảnh.

## Dùng thử

Mở `index.html` bằng trình duyệt là chạy (cần mạng để tải phông chữ từ Google Fonts), hoặc xem bản live tại https://kanz510.github.io/textmask-cho-anh/
